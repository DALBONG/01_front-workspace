window객체

윈도우 객체는 자바스크립트의 최상위 객체로, BOM과 DOM으로 나뉨.
- BOM(Browser Object Model) : location객체(주소창 관련), screen객체(창과 관련), navigator객체(브라우저 관련), history객체(뒤로가기 같은)
- DOM(Documetn Object Model) : document객체

[window.]open( ["url", "창이름", "창의 특성"] )


객체의 timer 관련 메소드

window.setTimeOut(함수, 일정 시간(ms))


- [window.]setInterval(함수, 일정시간ms)

DOM

html에 있는 각각의 요소들을 노드(node)라고 함.
- 요소 node(Element Node) : 태그 그 자체만을 의미 - 텍스트 node : 태그 내에 기록되는 내용

텍스트 노드가 존재하는 요소 (시작 /종료태그가 한쌍) : p, h1, div 등.. 텍스트 노드가 존재하지 않는 요소 (시작태그만 있음) : br, input 등...

노드(요소) 생성과 관련된 메소드

- 텍스트 노드가 존재하는 노드 생성(시작 + 종료태그)


- 텍스트 노드가 존재하지 않는 노드 생성
