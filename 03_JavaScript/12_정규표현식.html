정규 표현식

정규표현식 (REGEXP / REGEX : regular Expression)이란,
특정 패턴을 가진 문자열을 찾거나,
찾아서 변경(치환)할 때 사용하는 언어로,
정규 표현식을 이용하면, 문자열에 대한 특정 패턴 조건 검사시
복잡한 조건을 제시할 필요 없이 간단히 처리 가능

정규 표현식 객체 생성 및 정규표현식 관련된 메소드


메타 문자

메타문자를 이용해서 정규식으로 검색 조건으로 삼을 "특정 패턴" 제시 가능
문자열이 해당 정규식으로 제시한 특정 패턴에 만족하는지,
test()를 통해 검사하거나, replasce()를 이용해서 치환 가능.


플래그 문자

i : 대,소문자를 가리지 않고 비교 수행
g : 전역으로 비교를 수행
m : 여러줄 비교를 수행
