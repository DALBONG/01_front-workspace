jQuery개요

jQuery란?

기존 자바스크립트 언어 만으로 구현하기에 복잡한 구문 작성들을
간소화 하기 위해 "존 래식"에 의해 만들어짐.
JavaScript 기반 라이브러리(유용한 기능 모음집)
즉, JavaScript 언어로 유용한 함수나 내용들이 이미 정의되어있는 모음집

복잡한 자바스크립트 구문을 보다 짧고, 쉽게 개발 가능
(적은 양의 코드로 빠르고, 풍부한 기능 제공)

* 장점 :
1_ DOM 요소 => HTML태그들..과 관련된 스크립트를 보다 쉽게 구현 가능.
2_ AJAX(비동기 통신), 이벤트 처리 등.. 폭 넓게 지원.
3_ jQuery와 관련된 특성상 플러그인, 모든 ap

jQuery 라이브러리 연결 방법

head 태그 내 script 태그로 외부 jQuery관련한 .js파일을 연동
오프라인 / 온라인 방식 있음
- jQuery 공식 사이트 : 1. jQuery 라이브러리 직접 다운로드 받은 후 경로 지정 (오프라인)
2. CDN방식 (온라인) : ContentDelieveryNetwork 방식
- 파일을 받아 저장할 필요X, 라이브러리를 제공하는 사이트 url 제시해서 파일 경로 지정.


*jquery 구문 작성하기

jQuery 구문으로 DOM요소를 다루는 구문은
문서상의 요소들이 다 만들어 진 후 실행되어야 함

> 순수 자바스크립트에서는 

window.onload = function(){
실행내용; 
}
JS에서의 window.onload구문은 해당 문서 요소들이 다 로드되고 
+ 외부문서들(css파일)도 다 가지고 온 뒤에 실행 됨. 
그리고, 이 구문은 해당 문서에서 단 한번만 작성 가능(마지막것 반영)

해당 문서의 요소들만 다 로드되면 곧바로 실행 됨. 
+ 여러번 기술 가능함.(제한X) -> 순서대로 실행
> jQuery에서의 해당 내용은 3가지 구문으로 제공. 
1. jQuery(document).ready(function(){
    //실행내용
})

2. $(document).ready(function(){
    //실행내용
})

3. $(function(){
    //실행내용
})
