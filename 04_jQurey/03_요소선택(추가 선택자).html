* 속성 선택자

선택자[속성] : 특정 속성을 가지고 있는 모든 요소 선택
선택자[속성=값] : 속성값이 특정 값과 일치하는 모든 요소
선택자[속성~=값] : 속성 값에 특정값을 단어로 포함하는 모든 요소 선택
선택자[속성^=값] : 속성 값이 특정값으로 시작하는 요소 선택
선택자[속성$=값] : 속성 값이 특정값으로 끝나는 요소 선택
선택자[속성*=값] : 속성 값에 특정값을 포함하는 요소 선택
