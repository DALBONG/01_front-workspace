이벤트 핸들러(발생시 실행할 fucntion) 연결방법

방법 1. 이벤트 메소드를 통한 연결 

        $("선택자").이벤트메소드(function(){
            해당 이벤트 메소드 발생했을때 실행될 내용
        });

클릭


방법 2. on메소드를 이용한 방법

        $("선택자").on("이벤트명", function(){
            해당 선택자의 이벤트 발생시 실행할 내용
        })

마우스를 올려봐


* 방법 3. 상위요소 선택자 활용


        $("상위요소 선택자").on("이벤트명", "하위요소 선택자(이벤트 걸 요소)",function(){
            //꼭 쓸 때가 있으
            선택된 상위 요소 안에 존재하는 하위요소에 해당 이벤트 발생시 실행할 내용
        }).

h4 클릭

h5 클릭
div 바깥쪽 h5

* 키보드 관련 이벤트

- keydown | keypress : 키가 눌러질 때 발생하는 이벤트
ㄴ keydown : 모든 키가 눌러질 때 발생
ㄴ keypress : 키보드의 function키, 기능키(컨쉬알), 한글 제외한 나머지 키 눌러질 때 발생
- key up : 키가 떼어질 때 발생하는 이벤트
